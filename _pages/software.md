# Software

The PKU-EMBL Lab currently highlights two BASALT-family tools for genome-resolved microbiome research, microbial dark matter discovery, and reproducible environmental bioinformatics.

Our official GitHub organization is [PKU-EMBL](https://github.com/PKU-EMBL).
