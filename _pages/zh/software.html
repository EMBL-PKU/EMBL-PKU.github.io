开源软件

PKU-EMBL 实验室目前重点维护两个 BASALT 系列工具，服务于基因组解析的微生物组研究、微生物暗物质挖掘与可复现环境生物信息学分析。

实验室官方 GitHub 组织为 PKU-EMBL。

核心软件

BASALT

Binning Across a Series of Assemblies Toolkit：面向短读长与长读长测序数据的宏基因组分箱、基因组精炼与基因组解析分析工具集。

BASALT 是实验室核心软件，成果发表于 Nature Communications。

GitHub 234 stars
分析流程

BASALT-Air

轻量级 BASALT 系列流程，用于高效获取高质量宏基因组组装基因组（MAG）。
